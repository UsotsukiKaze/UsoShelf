## 发布签名

`scripts/configure-release-signing.py` 生成更新专用 Ed25519 私钥。私钥经当前 Windows 用户的 DPAPI 加密后位于被 Git 忽略的 `data/release-signing.dat`；只将公钥固定在应用源码中。不要删除该私钥，也不要将私钥或 data 目录加入发行附件。私钥备份需要保留 Windows 用户的解密能力。

`scripts/prepare-release.py` 整理包体时生成并自验证 `RELEASE_SIGNATURE.json`。今后的 GitHub Release 必须同时上传安装版、便携版、SHA256SUMS.txt 和 RELEASE_SIGNATURE.json。更新器从固定仓库的版本地址获取签名，因此 KazeApps 无需传递签名字段。缺失或无效的签名会阻止应用内更新。

这项签名与 Windows Authenticode 证书分开管理。本机尚无 CA 签发的代码签名证书，不能声称 EXE 已得到 Windows 信任。
